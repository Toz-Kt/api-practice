# API Practice

Learning to talk to APIs from Python, starting with a local Ollama model.

## Files
- `first_request.py`: sends a prompt to a local Ollama model and prints the reply.

## Requirements
- Python 3
- Ollama running locally, with a model downloaded
- `requests` (`python -m pip install requests`)

## Goal
A local AI assistant (and "friend") I can talk to from my computer.
Starting with a console chatbot, then voice and more...

Status: just started.
